Desktop-Agent …

Der Desktop-Agent verbindet deinen PC mit dieser Web-App. Dann funktionieren auch online alle PC-Funktionen: Apps öffnen, Lautstärke/Helligkeit, Tastatur & Maus, Dateien am PC, Browser-Automation, Nachrichten (WhatsApp/Telegram), Code- und Dev-Agent, Steam-Updates, Projekt-Überwachung und Bildschirmfotos.

python desktop_agent.py --server {{ server_url }} --token {{ profile.api_token }} --save

Mit --save merkt sich der Agent Server und Token (config/agent.json). Danach genügt python desktop_agent.py. Mit --push-config werden deine lokalen Einstellungen, Gedächtnis, Wissensdatenbank und der Google-Kalender-Token auf den Server übertragen.
